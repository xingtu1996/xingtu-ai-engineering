# 代码包模板（AI 生成代码包有样学样）

> 用途：新建代码包（后端/前端/harness）按此骨架落地。基准 `java-rules.md` §二 DDD + §七 复杂度 + 各 `_TEMPLATE`。步骤：定类型→复制骨架→建目录→填逻辑→过清单。

## 一、后端包模板（dc-service，完整树见 `服务目录结构样板.md`）

```
dc-<service>/src/main/java/com/示例企业/ctf/<service>/
├── controller/      收参校验
├── application/     编排+事务
├── domain/          对象+Mapper
├── client/          Feign+降级
├── query/           查询
├── listener/        监听→委托
├── infrastructure/  DAO
└── utils/           工具
```

禁止：直调 DAO/事务内远程/domain 带业务/无分页/空 catch/SQL `${}`/循环远程/不幂等。

## 二、前端包模板（React，基准 ctf-backend 实际结构）

```
src/
├── config/<模块>/      页面配置
├── containers/<模块>/  页面容器
├── components/<模块>/  组件
├── services/api.ts     API
├── interfaces/         类型
├── hooks/              hooks（状态/复用）
├── loaders/            加载/权限
├── language/           国际化
├── styles/             样式
└── type/               全局类型
```

规则：逻辑在 containers、UI 在 components、API 只经 services；新模块 `config`+`containers` 成对建。

## 三、harness 包模板（skill/agent/rule/hook/script）

| 类型 | 位置 | 骨架 | 注册 |
|------|------|------|------|
| Skill | `skills/{name}/` | SKILL.md+scripts/references/assets | 目录即注册 |
| Agent | `agents/{name}.md` | frontmatter+角色/范围/输出 | 目录即注册 |
| Rule | `rules/{domain}-rules.md` | 来源+规则+版本历史 | CLAUDE.md §九 |
| Hook | settings.json | 事件+command<500B | settings.json |
| Script | `scripts/{name}.sh` | 复制 `_TEMPLATE.sh` | 直接调用 |

新组件必经：`harness-gate.md` 准入五问 + `harness-size.sh` 门禁 + `CHANGELOG.md` 登记。

## 四、代码实现脚本模板（Service 方法骨架）

> 三段式：校验→幂等→业务+写库。

```java
if (orderId == null) {
    throw new BusinessException(ErrorCode.PARAM_INVALID, "orderId 不能为空");
}
Order exist = orderMapper.selectById(orderId);
if (exist != null) {
    log.info("已处理, orderId={}", orderId);
    return exist;
}
Order order = new Order();
order.setOrderId(orderId);
order.setStatus(OrderStatus.PROCESSED);
orderMapper.insert(order);
log.info("完成, orderId={}", orderId);
```

规范：application 写方法加 `@Transactional`；方法≤50/类≤500/嵌套≤3/参数≤5；ERROR 日志必传异常；注释只讲业务（无流程编号）。

## 五、检查清单

- [ ] DDD 分层正确？事务内无远程调用？
- [ ] 幂等/分页/参数化 SQL 齐全？
- [ ] 复杂度达标（≤50/500/3）？
- [ ] harness 新组件过准入+体积+CHANGELOG？
